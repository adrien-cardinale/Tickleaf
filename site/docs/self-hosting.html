Self-hosting

The relay is a small server that stores encrypted blobs and serves the web app. It holds no business logic and never sees your tasks in clear text.

Docker

git clone https://github.com/adrien-cardinale/Tickleaf.git
cd Tickleaf
docker compose up -d --build

Open http://localhost:3000. The relay database lives in the tickleaf-data volume, mounted on /app/data.

Without Compose:

docker build -t tickleaf .
docker run -d -p 3000:3000 -v tickleaf-data:/app/data tickleaf

HTTPS

Encryption also works over plain HTTP. Only the service worker (PWA install, offline mode) needs HTTPS or localhost. Put a TLS reverse proxy in front of port 3000 for remote access.

Configuration

Every variable has a default.

VariableDefaultRole
PORT3000Listening port.
DATABASE_PATH./data/relay.dbRelay SQLite database (/app/data/relay.db in the image).
ALLOW_SIGNUPtruefalse refuses any new key. Set it once your devices are connected.
STATIC_DIRapps/web/distWeb build folder to serve.
MAX_USER_BYTES512 MiBLog quota per key. 0 disables it.
RATE_LIMIT_PER_MINUTE300Requests per minute and per client. 0 disables it.
ALLOWED_ORIGINSemptyAllowed CORS origins, comma-separated.

Use it from this site

The app hosted on this site can sync with your relay. Add this site’s origin to ALLOWED_ORIGINS, then enter your relay address in the app. The desktop and Android apps need no CORS setting.
