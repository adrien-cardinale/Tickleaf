Reminders

A reminder rings a notification at a chosen date and time. It is independent of the due date: a task due Friday can remind you on Thursday evening.

Set a reminder

  1. Open the task detail.
  2. Fill the Rappel field with a date and time.
  3. On first use, allow notifications when the system asks.

The notification shows the task title, and its notes when it has some. A completed task never rings.

Where it rings

PlatformBehavior
AndroidThe system schedules the notification, so it rings with the app closed.
Windows, macOS, LinuxThe reminder only rings while the app is open, even minimized.
BrowserThe reminder is saved and synced, but never rings.

Reminders sync like the rest of the task: set one on your computer and your phone rings it.

Notifications blocked

If you refused the permission, Tickleaf shows Notifications désactivées when you set a reminder. Allow Tickleaf notifications in the system settings, then reopen the app.
