Desktop and Android apps

The native apps are the web interface packaged with Tauri 2. They work offline, ring reminders and sync through your server.

Install a release

Installers are attached to each release, and the download page picks the right one for your platform. They are not code-signed yet, so your system warns you on first launch:

  • Windows: SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.
  • macOS: Gatekeeper refuses to open the app. Right-click the app, choose Open, then confirm. If it says the app is damaged, run xattr -dr com.apple.quarantine /Applications/Tickleaf.app.
  • Linux: no warning. Make an AppImage executable first: chmod +x Tickleaf_*.AppImage.
  • Android: allow installs from your browser when Android asks.

Updates

Paramètres › Mises à jour shows the installed version and compares it with the latest release on GitHub.

  • Desktop: the app downloads the signed package, installs it and restarts.
  • Android: the app downloads the .apk of the release, which Android installs over the current one.
  • Browser: the page updates itself when the server deploys a new version.

A desktop update only installs if it is signed with the project key.

Connect synchronization

  1. On first launch, create a key, enter one, or scan a QR code on Android.
  2. Enter the server address on that screen, or later in Paramètres › Synchronisation.
  3. The app derives its credentials from the key and runs a first sync.

Build them

You need stable Rust and the Tauri prerequisites, plus the Android SDK, NDK and a JDK for Android.

bun run desktop:dev     # desktop window
bun run desktop:build   # desktop installers
bun run android:dev     # connected device or emulator
bun run android:build   # APK and AAB

Desktop installers land in apps/desktop/src-tauri/target/release/bundle.
