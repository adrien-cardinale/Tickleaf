Relay API

All routes live under /api. data is the base64 of a sealed blob: 8 MiB max per entry, 9 MiB max per request. Errors are JSON: { "error": "…" }.

RouteDescription
GET /api/healthReturns { "status": "ok" }.
POST /api/logAppends { "data" } to the log and returns { "seq" } (201). The first append from an unknown user id creates the account (403 if signups are closed). Later appends need the matching secret (401 otherwise). 413 when the quota is reached.
GET /api/log?since=<seq>&limit=<n>Returns { entries: [{ seq, data }], cursor, hasMore } for entries after since. limit defaults to 200, max 500. A page is also capped at 8 MiB. Call again with cursor while hasMore is true.
DELETE /api/accountDeletes the account and its whole log (204).

The log is append-only, numbered per account with a gapless sequence, and stored in SQLite in WAL mode.
