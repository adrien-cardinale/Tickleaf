Native apps for Windows, macOS, Linux and Android work offline, ring reminders and sync through your server. The web app needs no install at all.

Platforms

Windows

Windows 10 and 11, 64-bit.

  • Installer (.exe)
  • MSI package

SmartScreen warns on first launch: click More info, then Run anyway.

macOS

Universal disk image for Apple Silicon and Intel Macs.

  • Disk image (.dmg)

Gatekeeper blocks the first launch: right-click the app, then Open.

Linux

x86-64 packages for Debian, Fedora and the rest.

  • Debian, Ubuntu (.deb)
  • Fedora, openSUSE (.rpm)
  • AppImage

Make the AppImage executable first: chmod +x.

Android

APK to install directly on your phone.

  • Android (.apk)

Android asks you to allow installs from your browser.

Web

Runs in any modern browser and installs as a PWA. Your data stays on the device in IndexedDB, and sync is optional.

  • Open the app

Works on iPhone and iPad too, without reminders.

The installers are not code-signed yet, so Windows and macOS warn you on first launch. How to open them →
